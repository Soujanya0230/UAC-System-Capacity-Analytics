# System Capacity & Care Load Analytics for Unaccompanied Children

## Project Overview
This project analyzes historical data from the Unaccompanied Alien Children (UAC) Program to understand trends in CBP custody, transfers, HHS care, and discharges.

## Objectives
- Analyze HHS care and CBP custody trends.
- Identify peak workload periods.
- Compare yearly averages.
- Examine monthly transfers and discharges.
- Generate insights using data visualization.

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Findings
- Average HHS care count: 6,061.28
- Maximum HHS care count: 11,516
- Average CBP custody count: 171.49
- Maximum CBP custody count: 531

## Visualizations
1. HHS Care Trend Over Time
2. CBP Custody Trend Over Time
3. Yearly Comparison
4. Monthly Transfers and Discharges
5. Peak Workload Comparison

## Conclusion
The project demonstrates data cleaning, exploratory data analysis, statistical analysis, and visualization using Python.

## Limitation
The dataset does not contain actual facility capacity or staffing data. Therefore, the analysis measures recorded workload trends rather than actual capacity utilization.
